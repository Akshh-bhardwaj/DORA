# Dora - Your Smart Chatbot

A frontend user interface designed to act as a chatbot buddy. This project allows users to converse with an AI entity modeled locally.

## Features
- **Modern UI**: Clean message bubbles with a fixed input area.
- **Custom Assets**: Customized AI and User profile pictures.

## Structure
- `css/`: Contains styling logic.
- `js/`: Contains interaction logic and potential API request handling.
- `assets/`: Contains images.

## Setup
Simply open `index.html` in your browser.
