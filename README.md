A premium, modern frontend user interface designed to act as your intelligent chatbot buddy. This project allows users to converse with an AI entity modeled locally.

## ✨ Features
- **Stunning Dark Mode UI**: A beautiful, glassmorphic layout floating over an animated mesh gradient background.
- **Dynamic Interactions**: Features micro-animations, custom typing delays, and smooth auto-scrolling.
- **Custom Assets**: Customized AI (Dora) and User profile picture avatars via `ui-avatars`.

## 📂 Structure
- `css/`: Contains styling logic, flexbox layouts, and animations.
- `js/`: Contains interaction logic, dynamic AI responses, and DOM updates.
- `assets/`: Contains additional static assets and images.

## 🚀 Setup
Simply open `index.html` in your favorite modern browser and say hi to Dora!
